# Додеп

Мем-аркада по мотивам стримов: лови заносы, уворачивайся от «х1 в собаках», корми маму птицу депами, покупай бонуску «Собачья будка» и улучшения в магазине.

Пародия на мемы со стримов. Настоящее казино забирает настоящие деньги.

- `aura-farm.html` — игра (единственный исходник).
- `build_ios.py` — собирает версию для iPhone в `ios/`: `python3 build_ios.py assets/boss.png`.
- `ios/` — готовое веб-приложение; публикуется на GitHub Pages из ветки `gh-pages`.

На iPhone: открыть сайт в Safari → «Поделиться» → «На экран „Домой“».
